# Coding Agent Instructions

## Role
You are the implementation agent for this project.

Read all project MD files before making architectural decisions.

## Non-negotiable rules
1. Do not invent major features.
2. Do not replace working components without a reason.
3. Keep components reusable.
4. Keep data/configuration separate from UI.
5. Keep secrets out of frontend code.
6. Make the site responsive.
7. Test forms and error states.
8. Do not claim a form submission succeeded when the backend failed.
9. Do not hard-code the WhatsApp number in multiple components.
10. Keep pricing and important terms visible.
11. Do not add sponsorship functionality.
12. Do not build employer accounts or complex admin systems.
13. Use natural, human copy.
14. Avoid AI-sounding marketing language.
15. Keep the visual structure close to the supplied reference without making the project a meaningless collection of copied sections.

## Implementation sequence
### Step 1

### Step 2

### Step 7

### Step 8

### Step 9
Build confirmation and WhatsApp handoff.

### Step 10
Build legal/information pages.

### Step 11
Test desktop/mobile/accessibility/error states.

## Before coding
Create a short implementation checklist from these MD files and mark each item as:
- not started
- in progress
- complete
- blocked

Do not wait for clarification on small implementation details; choose the simplest reasonable approach and document it.

For business/legal wording that is not specified, use clearly marked placeholder copy rather than inventing promises.
