## Find Opportunities
The first version should provide:
- Keyword/job title search
- Location search
- Clear category entry points
- Introductory information
- Application CTA

Do not build employer posting or applicant account systems.

## Routing
Use clean, readable URLs and normal browser navigation. Protect the application route from accidental data loss with appropriate confirmation behaviour where useful.
