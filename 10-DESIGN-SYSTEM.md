# Design System

## Reference
Follow the supplied Bupa care-services experience for the overall visual language and component rhythm.

## Principles
- Clean
- Warm
- Reassuring
- Spacious
- Accessible
- Mobile-first
- Strong typography hierarchy
- Clear calls to action

## Components
Create reusable components for:
- Header
- Navigation
- Hero
- Search
- Buttons
- Cards
- Category cards
- Image/content split sections
- Steps
- Pricing/plan cards
- FAQ accordion
- Article cards
- Form fields
- Checkboxes
- Alerts
- Footer

## Images
Use relevant, high-quality care/work imagery appropriate to the section. Keep image proportions and treatment consistent.

Images must have meaningful alt text when informative. Decorative images should be marked appropriately.

## Responsive behaviour
Check at:
- small mobile
- large mobile
- tablet
- laptop
- large desktop

Do not simply shrink desktop layouts. Reflow navigation, cards, forms and search controls appropriately.

## Accessibility
Target WCAG-friendly implementation:
- semantic HTML
- keyboard navigation
- visible focus
- sufficient contrast
- labels for inputs
- accessible errors
- meaningful button names
- sensible heading order
