# Care Careers Website — Project Overview

## Objective
Build a polished care-careers website prototype inspired by the structure and user experience of the supplied Bupa Care Services page. The project is a software-development interview demonstration.

The website is for people interested in opportunities to work in UK care homes. It should support people already in the UK and people outside the UK.

## Core experience
Home → Find opportunities → Learn about the service → Apply → Accept Terms & Conditions → Select service plan → Submit → Save application to Google Sheets → Continue to WhatsApp for assistance/payment information.

## Content tone
Use warm, reassuring, plain-English care-services copy. Keep sentences natural and concise. Avoid generic AI marketing language, exaggerated claims, buzzwords and unnecessary copy.

## Reference
Use the supplied Bupa Care Services page as the main reference for page structure, component hierarchy, spacing, interaction patterns and visual rhythm.

Do not blindly reproduce every section. Every component must be classified as KEEP, ADAPT, REPLACE, REMOVE or ADD.

## Initial service plans
- 3 years — £4,000
- 5 years — £6,000
- Initial payment — £1,000

The first version does not process payments on the website. After the relevant application/terms step, the user is handed to WhatsApp for assistance and payment information.

## Data
Use Google Sheets as the initial lightweight application datastore. Do not build a complex database, employer portal, applicant portal or CMS unless later requested.

## Job experience
The initial search should focus on:
- Job title / keyword
- Location

Support care-related categories including Care Assistant, Senior Care Assistant, Support Worker, Healthcare Assistant, Registered Nurse, Senior Carer, Live-in Carer, Home Care Worker and Dementia Care Worker.

There is no sponsorship feature in this version.

## Development rule
Build only what is required. Do not invent major features. Keep the code modular, maintainable, responsive and easy to extend.
